## 环境 / 网络
- 工作区 `e:\3.5ESP32`（git 仓库，remote = `https://github.com/YouthherE/3.5ESP32.git`，本地分支 `master`，当前无 upstream 跟踪）。
- **GitHub 直连不可用**：`Invoke-WebRequest https://github.com`（含 codeload.github.com）均超时；git 未配置任何 http/https proxy → 任何 fetch/pull/push/clone 都会报 `Failed to connect to github.com port 443 after 21060 ms`。
- 解决方向：给 git 配本地代理（`http.proxy` / `https.proxy`，端口常见 7890/10809/8889），或改用镜像地址 / SSH over 443。
- 注意：未经用户明确同意不要直接改 git config，先给出命令让用户自己执行。
